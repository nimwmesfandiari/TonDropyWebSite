# پایش

## هشدارهای خودکار (تلگرام ادمین‌ها)
- 🚨 **مغایرت حسابداری** (`reconcile`): موجودی‌ها ≠ ledger، یا ≠ واریزها − برداشت‌های انجام‌شده. حداکثر ساعتی یک‌بار. **این هشدار را جدی بگیرید و معاملات را متوقف کنید تا علت پیدا شود.**
- ⚠️ خطای watcher واریز.
- ⏰ برداشت‌های معطل بیش از ۶ ساعت.

## چیزهایی که باید خودتان پایش کنید
| مورد | روش |
|---|---|
| خطاهای 5xx و latency | Workers Observability (فعال است) / Logpush |
| کهنگی قیمت | `GET /market/prices` ⇒ `available:false` مدت‌دار |
| موجودی خانه | `/admin/stats ⇒ houseBalances` (منفی شدن TON/USDT = نیاز به تامین) |
| موجودی کیف داغ واقعی در بلاک‌چین ≥ مجموع بدهی کاربران | کار دستی/اسکریپت جدا |
| واریزهای `deposit.unmatched` | `GET /admin/audit` |
| ظرفیت D1/KV/R2 و Rate limit Cloudflare | داشبورد Cloudflare |

## نکته
`reconcile` فقط سازگاری **داخلی** را می‌سنجد؛ تطبیق با موجودی واقعی بلاک‌چین و حساب بانکی باید روزانه و دستی/جداگانه انجام شود.
