# قرارداد زمان و تاریخ

- **ذخیره‌سازی**: همه زمان‌ها Unix epoch به **ثانیه (UTC)**، `INTEGER`. تابع `nowSec()`.
- **API**: همان اعداد ثانیه‌ای (`createdAt`, `expiresAt`)؛ مصرف‌کننده تبدیل می‌کند.
- **نمایش**: فرانت با `toLocaleString("fa-IR", { timeZone: "Asia/Tehran" })` (تقویم شمسی و ارقام فارسی توسط ICU مرورگر).
- **تاریخ تولد** (KYC): رشته ISO `YYYY-MM-DD` میلادی؛ ورودی `<input type="date">`. سن حداقل ۱۸ سال با `ageInYears` (UTC).
- **پنجره‌ها**: سقف برداشت روزانه = پنجره **غلتان ۲۴ ساعته**، نه روز تقویمی. آمار `last24h` ادمین هم همین‌طور.
- **انقضاها**: quote ۳۰ ثانیه، JWT ۱۲ ساعت، initData تلگرام ۲۴ ساعت، رفرال معلق ۷ روز.
- **ساعت سرور**: Cloudflare از NTP استفاده می‌کند؛ هیچ منطقی به ساعت کلاینت اعتماد نمی‌کند (شمارنده quote در UI فقط نمایشی است و سرور انقضا را اجرا می‌کند).
