# نقش‌ها و شیوه کار (انسان و ایجنت)

| نقش | مسئولیت | مرز اختیار |
|---|---|---|
| **UI/UX** | `frontend/`، متن‌های فارسی، دسترس‌پذیری | تصمیم مالی نمی‌گیرد؛ فقط API را صدا می‌زند |
| **Backend** | `backend/src`، قواعد معامله | هر تغییر موجودی فقط از `lib/ledger.move` |
| **Database** | `backend/migrations` | فقط migration جدید؛ مایگریشن اعمال‌شده تغییر نمی‌کند |
| **Security/QA** | تست، بازبینی، `docs/hack.md` | حق veto روی تغییرات مالی |
| **Ops** | استقرار، secretها، پایش | تنها نقشی که به secretها و کلید ارسال دسترسی دارد |

## قواعد برای ایجنت‌های AI روی این مخزن
1. قبل از هر commit: `npm test && npm run check`.
2. هرگز secret، توکن یا کلید را در کد/مستند/لاگ ننویس.
3. تغییر منطق پول (`money.js`, `ledger.js`, `orders.js`, `wallet.js`, `admin.js`) فقط با تست جدید و بازبینی انسانی.
4. به‌جای حدس زدن فرمت API خارجی (Toncenter) از پاسخ واقعی استفاده کن و در `docs/` ثبت کن.
5. تغییرات را کوچک و جدا کامیت کن؛ پیام کامیت بگوید «چرا».

## گردش کار
شاخه ⇒ تغییر + تست ⇒ PR ⇒ بازبینی (برای مسیرهای مالی حتماً انسان) ⇒ staging ⇒ production.
